## 설계·계약

### 링크 등록·처리함

- 처리 항목은 `ownerId`, 원본 링크, 접수 시 선택한 대상 맵 ID, 대상별 상태·결과 장소 ID, 분석/보완 상태를 가진다. 개인 처리함은 본인 항목만 반환한다.
- 웹 등록 기본 대상은 현재 접근 가능한 맵, DM 접수 기본값은 사용자 설정이다. 항목을 만들 때 대상을 스냅샷으로 보존한다. 대상은 본인 개인 맵·참여 공유 맵·둘 다 중에서 고른다.
- 링크는 형식·프로토콜을 검사하고 인스타 게시물·릴스와 미지원 출처를 구분한다. 미지원은 링크 보관·직접 장소 연결만 제공한다. 링크를 외부에서 열거나 분석하지 않는다.
- 목 데이터의 처리 결과 확인은 명시적 액션으로 진행한다. 접수 화면과 저장 결과 화면을 분리한다. 실제 분석이 수행되는 것처럼 처리하지 않는다.
- 저장·재시도 직전에 대상 맵 권한과 항목 소유권·삭제 여부를 재확인한다. 대상별 성공·실패를 기록하고 재시도는 실패한 대상에만 적용한다. 완료 장소는 기존 상세·복제로 연결한다.
- 같은 링크는 선택한 맵의 기존 카드로 연결한다. 같은 지점의 다른 출처는 해당 맵의 출처만 추가하고 메모·수정·방문 상태를 보존한다. 다른 맵의 카드 존재는 자동 공유 근거가 아니다.
- 모호한 지점은 후보 선택·직접 장소 검색 전까지 저장·핀 생성하지 않는다. 장소 없음·메뉴 없음·접근 불가·위치 미확정을 별도로 표시한다. 여러 장소 중 일부만 저장한 결과와 남은 보완 항목을 구분한다.
- 직접 장소 연결은 `inputOrigin: manual`로 표시하며 게시물 분석 결과·메뉴를 새로 추측하지 않는다. 미지원 출처는 인스타 출처로 표시하지 않는다. 수동 입력의 출처 구분은 다른 맵에 복제해도 유지한다.
- 여러 장소의 보완은 하나의 원본 처리 항목에 묶는다. 일부 장소의 대상별 실패가 남으면 전체를 완료로 표시하지 않고 해당 부분만 다시 처리한다. 원본 처리 항목 삭제는 미완료 하위 처리를 함께 막고 저장된 장소는 보존한다.
- 대상 변경은 아직 저장하지 않은 대상에 적용한다. 이미 성공한 항목은 복제로 다른 맵에 넣는다. 공유 권한 종료 시 종료된 맵은 선택지에서 제외하고 성공한 개인 저장을 보존한다.
- 여러 장소의 하위 항목도 부모가 보관한 실제 맵 ID를 그대로 사용한다. 새 연결의 공유 맵은 명시적 대상 변경으로만 추가한다. 대상 변경은 미완료 하위 항목에도 적용하고 완료한 대표 장소·하위 장소와 성공 이력은 다시 공유하지 않는다. 새 대상에서 아직 저장하지 않은 하위 항목도 통합 결과에서 다시 처리할 수 있다.
- 원본 입력 URL을 별도로 보존한다. 인스타 게시물의 중복 비교 주소 정규화와 미지원 출처의 콘텐츠 식별 쿼리를 구분한다. 출처별 원본 버튼은 그 출처의 URL을 안내한다.
- 지점 키가 없는 수동 장소는 처음 선택한 기본 장소 정보의 불변 식별값을 보존한다. 이후 표시 이름·카테고리를 고쳐도 같은 링크·장소를 새 카드로 만들지 않으며 복제 후에도 식별값을 유지한다. 이 값에 맵·개인 장소 ID나 메모·사진 등 개인 추가 정보를 넣지 않는다.
- 저장된 장소가 있는 항목은 과거 안내에서 링크 보관을 다시 눌러도 완료·부분 성공 상태를 유지한다. 결과에서는 실제 저장된 접근 가능 맵별 이동을 제공하고 검색·조회 필터를 초기화한다. 수동 장소 검색은 검색어에 맞는 후보를 먼저 고른 뒤 같은 지점의 중복 후보를 제외한다.
- 완료한 대표 장소는 과거 보완·검색 화면의 재분석·재확정으로 처리 상태를 되돌리지 않는다. 수동 검색에서 지점 키 없는 기존 카드를 선택해도 같은 맵의 카드를 재사용한다. 선택 시 접근 가능한 실제 카드와 대조한 참조를 유지하고 저장·재시도 직전에 권한·삭제 여부를 재확인한다. 미확정 카드는 맵별로 구분해 선택할 수 있다.
- 연결 대기 항목은 본인 확인 중 항목 ID를 유지하고 같은 항목의 처리를 요청한다. 공개 범위는 현재 접근 가능한 공유 맵의 실제 참여자 이름으로 안내한다.
- 보완 본문·캡처는 목업 내 상태로만 취급하고 외부 전달·파일 업로드·추출을 하지 않는다. 항목 삭제는 그 항목의 후속 처리를 막으며 이미 저장한 장소를 삭제하지 않는다.

### 이번 약속·설정

- 후보는 접근 가능한 활성 공유 맵의 삭제되지 않은 장소만 포함한다. 목업 표현대로 후보 최대 3곳·한 사람이 최종 1곳 선택·공유 장소 방문 상태를 사용한다. 이는 실제 서비스의 미정인 공동 기준·확정 권한·방문 단위를 결정하는 정책 변경이 아니다.
- 후보 교체는 후보 목록만 바꾸고 장소를 삭제하지 않는다. 개인 장소는 기존 복제 미리보기 흐름을 거쳐 공유 맵에 넣은 뒤 후보로 추가한다. 공유 권한 종료·삭제 장소는 후보·선택 액션에서 거부한다.
- DM 기본값 변경은 이후 접수에만 적용하고 기존 처리 항목 대상을 바꾸지 않는다. 공유 맵/둘 다 선택 시 공개 범위를 설명한다.
- 내보내기는 접근 가능한 맵의 기본 기록·처리 상태만 구조화해 요청 내용을 확인한다. 비공개 다른 맵·내부 복제 관계·원본 미디어를 포함하지 않으며 미정인 다운로드 형식은 정하지 않는다.
- 휴지통 조회·복구는 선택한 접근 가능 맵에만 적용한다. 공유 종료는 본인 멤버십만 종료하고 개인 장소·복제본·남은 참여자의 공유 기록·DM 연결을 보존한다. 유효하지 않은 본인 DM 기본 대상만 개인으로 바꾼다.
- 기록 삭제·계정 탈퇴는 미정 정책 안내와 내보내기 진입만 제공한다. 영구 삭제는 구현하지 않는다.

5. `web/src/router.js`, `screens/catalog.js`, `components/tab-bar.js`, 지도·시작·상세 화면: 실제 새 경로로 연결하고 `todo/UI-03`, `todo/UI-04`를 제거한다. 58개 카탈로그와 검사 스크립트·기존 테스트 기대값을 갱신한다.
