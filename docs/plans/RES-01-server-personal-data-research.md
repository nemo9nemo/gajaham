## 범위·하지 말 것

공식 서비스 사례4개와 로컬/클라우드/공유 혼합 구조, 사용자별 인가·무료/유료 운영 비용·메일/도메인·데이터량 가정을 비교한다. WEB-00·진행표·기존 시장조사에 후속 조사 링크를 추가하고 공식 Hosting 한도 표기 차이를 보완한다. 개인 원본 로컬 정책을 자동 변경하지 않고 운영 계정/DB·API/의존성·유료 계약·도메인 구매·공개 배포·push/PR은 실행하지 않는다. 관련 없는 `.claude/launch.json`은 보존한다.

## 조사·검증 방법

1. 현재 결정0005/0007·웹 로컬 계약과 구현/미구현 경계를 확인한다.
2. 사례는 공식 도움말·처리방침·설치 문서, 요금·제약은 제공자의 공식 문서로 확인한다. 기술/DB 미공개는 미확인으로 남긴다. 실제 사용/시장 통계와 공개 문서상 설명을 구분한다.
3. Supabase 공식 MCP 문서 검색과 changelog/요금/RLS/메일/백업 문서를 확인한다. changelog Markdown URL은 web 도구가 content-type을 지원하지 않아 HTML changelog로 대체한다. 운영 프로젝트/사용자 데이터는 조회하지 않는다.
4. 가상 데이터량·읽기 계산을 독립 산술 검사하고 변경 Markdown의 상대 링크·`git diff --check`를 확인한다. 문서 전용 변경이므로 웹/Android 회귀·브라우저·기기·배포 검사는 재실행하지 않는다.
5. 별도 읽기 전용 구현 리뷰 후 로컬 커밋하고 고정 SHA를 별도 worktree에서 main 대비 재리뷰한다.

완료 기준은 사례/추론/가격·한도/미확인을 구분하고 ‘개인 비공개’와 ‘로컬 전용’의 정책 차이를 설명하며, 현재 정책을 그대로 유지하는 것이다.
