## 최소 비용안: 무료 주소로 작은 검증부터

**Firebase Auth + Firestore Standard의 계정 원본 + Firebase Hosting, 게스트만 IndexedDB**를 우선 구현 방향으로 한다. 운영 프로젝트가 있다는 뜻은 아니다. 기본 CRUD의 무료 범위와 서버 탈퇴 정리·운영 백업/보존·사진/DM 비용을 별도로 검토한다. 유료 자동 활성화·운영 배포는 하지 않는다.

| 항목 | 시작 비용/한도 | 비용·운영 경계 |
|---|---|---|
| 도메인·HTTPS | Hosting 기본 주소 `선택한사이트ID.web.app`와 HTTPS 0원 | 실제 주소 미발급. `firebaseapp.com`과 혼용하지 않고 한 주소를 정식으로 사용. 자체 도메인 구매는 선택·별도 비용 |
| 정적 Hosting | Spark 0원, 저장10GB. 전송은 공식 요금표360MB/일·세부 문서10GB/월 표기 차이 있음 | 프로젝트 전체 한도. 무료 초과 시 중단 가능하므로 운영 프로젝트 Usage/적용 정책 확인 필요. 월 한도만으로 하루 유입 허용량을 보장하지 않음. 배포 이력도 저장량에 포함 |
| 이메일·비밀번호 인증 | Spark의 무료 범위 사용 | 확인 메일1,000건/일·암호 재설정150건/일 등 제한. 매직링크·SMS·Identity Platform 추가 기능의 한도를 혼동하지 않음 |
| 계정 개인 원본/공유 DB | Firestore 무료 범위: 1GiB·읽기50,000/일·쓰기20,000/일·삭제20,000/일·외부전송10GiB/월 | 개인+공유의 프로젝트 합계. UID별 인가·공유 참여권·삭제/정리·구독/재접속 비용을 검증. 일정 이용자 수까지 무료라고 단정하지 않음 |
| 게스트 개인 DB | 브라우저 IndexedDB 0원 | 현재 브라우저/프로필/origin에만 원본. 사용자 선택 후 서버에 저장 확인된 계정 기록은 다른 기기 조회 가능 |
| 지도·검색 | 무료 적용 자격/호출량 확인 후 결정 | 카카오는 개발자 계정의 첫 활성화 앱만 무료 쿼터. 보유 앱/계정 상태 미확인이라 무료를 보장하지 않음 |
| DM·자동 분석·이미지 | 기본 비용 계산에 미포함 | 현재 미구현. 도입 전에 원가와 상한을 별도 산정 |

조건부로 **도메인·호스팅·기본 인증의 월 고정비 0원으로 소규모 검증을 시작할 수 있다.** 모든 기능을 무제한 무료로 운영한다는 뜻은 아니다. 지도·공유·메일 사용량과 제공자 조건, 실제 트래픽을 보고 다시 산정한다. 사람의 개발/운영 시간·통신 요금 등은 이 인프라 계산에 포함하지 않는다.

요금/한도 확인일은 2026-11-03이다. [Hosting 기본 주소/HTTPS](https://firebase.google.com/docs/hosting/), [Hosting 한도/초과 시 처리](https://firebase.google.com/docs/hosting/usage-quotas-pricing), [Spark 조건](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans), [인증 한도](https://firebase.google.com/docs/auth/limits), [Firestore 무료 한도](https://firebase.google.com/docs/firestore/quotas), [카카오 무료 적용 조건](https://developers.kakao.com/docs/ko/kakaomap/common)을 근거로 했다. 자동 유료 전환을 기본값으로 두지 않는다. 추후 Blaze를 검토하더라도 예산 알림은 결제 상한이 아니므로 호출 제한·차단과 함께 설계해야 한다.

추가 확인한 [Firebase 공식 요금표](https://firebase.google.com/pricing)는 Hosting 전송360MB/일, 위 세부 문서는10GB/월을 제시한다. 독립적으로 모두 쓸 수 있는 할당량으로 계산하지 않으며 운영 프로젝트의 실제 적용 한도를 확인한다. 한도 검토용 가상 예로 회당1MB 전송이면360MB는 대략360회 분량이지만 캐시·업데이트·실제 바이트에 따라 달라지고 이용자 정원을 뜻하지 않는다. 지도 SDK 등 외부 전송은 별도다. 공유 맵100개 문서를 하루500회 전부 읽으면50,000읽기이므로 무료 DB도 조회 범위와 재접속을 관리해야 한다. 실제 사용 측정치가 아닌 계산 예다.
