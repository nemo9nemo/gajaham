# 가자함 — 개인 맵·코드 연결·맵 간 복제 기획

작성일: 2026-10-12. 사용자 추가 요구를 제품 기획으로 구체화한 문서다. 실제 기능 구현과 계정 연결은 수행하지 않았다.

**사용자가 요청한 범위**

- 개인 맵을 사용할 수 있다.
- 코드로 두 사람을 연결하면 둘의 공유 맵을 사용할 수 있다.
- 연결할 때 개인 맵의 장소를 공유 맵에 복제할지 선택할 수 있다.
- 연결 이후에도 개인 맵과 공유 맵 사이에 장소를 복제할 수 있다.
- 새 장소를 어느 맵에 등록할지 정할 수 있다.

아래의 맵 개수, 기본 저장 위치, 복제 후 동작, 메모 포함 기본값은 이 요구를 실행 가능한 형태로 만든 초기 제안이다.

**기본 구성**

| 맵 | 볼 수 있는 사람 | 역할 |
|---|---|---|
| A의 개인 맵 | A | 혼자 모으는 장소와 개인 메모 |
| B의 개인 맵 | B | 혼자 모으는 장소와 개인 메모 |
| A·B의 공유 맵 | A와 B | 둘이 공개하기로 선택한 장소와 공동 선택 |

초기에는 사용자당 개인 맵 1개와 활성 공유 맵 1개, 공유 맵의 참여자 최대 2명을 제안한다. 개인 맵은 코드 연결 후에도 유지한다. 각자의 개인 맵은 본인만 볼 수 있고, 공유 맵에는 선택한 장소만 담긴다. 코드로 연결하는 대상은 서비스 사용자와 공유 맵이며, 인스타그램 DM 계정 연결은 별도로 확인한다.

**코드로 연결하는 흐름**

1. A가 개인 맵에서 `함께 쓰기 → 연결 코드 만들기`를 선택한다.
2. B가 로그인한 뒤 코드를 입력하고 연결 대상 사용자를 확인한다. 이미 개인 맵을 사용 중이어도 그대로 진행한다.
3. 연결이 완료되면 공유 맵을 만들고 두 사람을 참여자로 등록한다. 두 사람의 개인 맵은 계속 사용할 수 있다.
4. 각자 자신의 개인 맵에 대해 `지금 복제 안 함 / 선택한 장소 복제 / 전체 장소 복제`를 선택한다.
5. 복제할 장소, 대상 맵, 메모·사진 등 추가로 포함할 항목을 미리 확인한 뒤 실행한다.
6. 개인 맵과 공유 맵을 전환하며 사용한다. 초기 복제 선택은 나중에도 다시 할 수 있다.

한 사람이 복제를 마칠 때까지 상대방의 사용을 막지 않는다. 상대방의 개인 장소 목록은 초기 복제 화면에서도 본인에게만 보인다. 연결 코드는 만료·취소·사용 완료 상태를 갖고 재발급 시 이전 코드를 무효화한다. 코드 입력만으로 바로 기록을 열지 않고 로그인과 연결 확인을 거친다. 이미 활성 공유 맵에 참여 중이면 현재 연결을 안내하고 새 연결로 자동 교체하지 않는다.

**새 장소의 등록 위치**

저장 화면에 현재 대상과 공유 범위를 보여주고 `개인 맵 / 공유 맵 / 둘 다`를 선택하게 한다. 연결 전에는 개인 맵을 제공한다. 연결 후에도 사용자가 선택한 개인 맵 기본값을 유지한다.

| 입력 | 초기 제안 |
|---|---|
| 모바일 웹에서 링크 추가 | 현재 보고 있는 맵을 기본으로 표시하고 저장 전에 변경 가능. `둘 다`도 선택 가능 |
| 인스타그램 DM 전달 | 사용자별 기본 저장 위치 사용. 최초 기본값은 개인 맵이며 설정에서 공유 맵 또는 둘 다로 변경 가능 |
| DM 한 건의 저장 위치 조정 | 접수 안내의 웹 처리 화면에서 등록 전에 대상을 확인·변경 가능. 등록된 뒤에는 다른 맵에 복제 가능 |
| 공유 맵 연결 종료 | 해당 공유 맵을 기본으로 쓰던 설정을 개인 맵으로 바꾸고 안내 |

DM 기본값을 공유 맵 또는 둘 다로 바꿀 때는 이후 전달한 장소가 상대방에게 보인다는 점을 설정 화면에 표시한다. 기본값 변경은 이후 접수되는 항목에 적용한다. 처리 중 항목의 대상은 접수 시점 선택을 유지하고, 사용자가 해당 항목에서 명시적으로 바꿀 수 있다. 자동 저장이 먼저 완료되면 다른 맵에 복제하는 동작으로 제공하며, 공유 맵에서 이미 보인 사실이 저장 위치 변경으로 취소되는 것처럼 안내하지 않는다.

새 장소 저장과 맵 전환은 별개의 행동이다. 웹의 현재 맵을 바꾸었다고 DM 기본 저장 위치까지 바꾸지 않는다. 저장 완료에는 실제 등록한 맵 이름과 결과를 표시한다. `둘 다`에서 한쪽만 성공하면 맵별 완료·실패를 나눠 보여주고 실패한 대상만 다시 처리할 수 있게 한다.

**연결 이후의 복제**

- 개인 맵 → 공유 맵: 개인적으로 모아 둔 장소를 둘의 지도에 추가한다.
- 공유 맵 → 내 개인 맵: 함께 모은 장소를 내 지도에도 보관한다.
- 카드 1개, 여러 장소 선택, 맵의 전체 장소를 대상으로 복제할 수 있다.

다른 참여자의 개인 맵은 복제 대상으로 보이지 않는다. 복제 직전에 대상 맵 접근 권한을 확인하고 원래 맵의 항목은 유지한다. 권한이 끝난 공유 맵의 기록을 옛 결과 링크로 새로 복제할 수 없다.

복제 결과는 각 맵에서 별도로 편집한다. 이후 메모·방문 상태·위치 보정·삭제가 다른 맵에 자동 적용되지 않는다. 사용자는 필요할 때 다시 복제하여 새로운 출처를 추가할 수 있다. 대상 맵에 같은 지점이 있으면 기존 카드에 누락된 출처를 추가하고 기존 사용자 수정·메모·방문 상태를 보존한다. 서로 다른 지점은 별도 장소로 유지하고 위치 미확정 항목은 미확정 상태로 복제한다.

**복제할 정보와 중복 처리**

| 정보 | 복제 제안 |
|---|---|
| 장소·지점·주소·좌표·카테고리 | 복제 시점의 정보와 사용자 위치 보정을 담음. 대상의 기존 수정 정보는 보존 |
| 요약·메뉴·방문 팁·원본 URL·근거 | 표시·보관 가능한 정보를 출처와 함께 복제 |
| 개인 메모·직접 올린 사진·개인 방문 기록 | 포함 여부 선택. 공유 맵으로 복제할 때 기본 선택 해제 |
| 공유 메모·사진 | 읽을 권한이 있는 항목 중 선택하여 내 개인 맵에 복제 |
| 관심 표시·공동 약속·상대방의 개인 평가 | 대상 맵에서 새로 관리 |
| 복제 기록 | 원 저장자, 복제한 사람, 복제 시각을 구분하여 기록 |

`전체 장소 복제`는 장소 선택 범위를 전체로 바꾸는 동작이다. 개인 메모·사진 포함 여부는 별도로 확인한다. 사용자가 보는 기록에 비공개 원본 맵의 이름이나 다른 개인 기록이 노출되지 않게 한다. 공통 장소 정보와 각 맵의 메모·수정·상태를 나눠 저장한다.

이미 분석한 항목은 결과를 재사용하여 복제한다. 새로운 URL을 분석하는 작업과 이미 저장된 결과를 다른 맵에 담는 작업을 구분한다. 같은 요청을 다시 실행해도 대상 맵에 같은 장소 핀이 반복 생성되지 않는다.

**연결 해제와 기록**

개인 맵과 이미 개인 맵에 복제한 기록은 연결 해제 후에도 유지한다. 나간 사용자의 공유 맵 접근은 종료한다. 공유 종료 화면에서 접근 종료 시점과 남는 공동 기록을 안내하고, 종료 전에 권한이 있는 공유 장소를 개인 맵에 복제할 선택을 제공한다.

나머지 참여자의 공유 기록은 기존 기록 관리 정책에 따라 보존한다. 새 상대와 연결할 때는 새로운 공유 맵을 만들며 이전 공유 맵의 기록이 새 상대에게 자동 공개되지 않는다. 마지막 참여자의 나가기·탈퇴와 공유 맵의 보관 기간은 별도 데이터 관리 정책으로 확정한다.

공유 맵을 대상으로 처리 중이던 작업이 저장 전에 권한을 잃으면 개인 처리함에서 대상 변경을 요청한다. 삭제하거나 권한이 끝난 공유 맵으로 저장하지 않는다. 접수 시 선택했던 대상과 실제 완료 대상을 구분하여 기록한다.

**필요한 화면과 데이터**

화면에는 개인/공유 맵 전환, 연결 코드 생성·입력, 초기 복제 선택, 저장 위치 선택, 복제 미리보기·완료 결과, 기본 DM 저장 위치 설정이 필요하다. 장소 카드에는 현재 맵 이름과 `다른 맵에 복제`를 제공한다. 공유 후보 선택은 공유 맵의 장소를 대상으로 하고, 개인 장소를 후보에 넣으려면 공유할 내용을 확인한 뒤 공유 맵에 복제한다.

데이터에는 맵 종류·소유자·참여자, 코드 상태, 사용자별 기본 저장 대상, 수신 작업별 저장 대상, 맵별 저장 장소·출처·메모·방문 상태, 복제 이력을 둔다. 원 장소와 참고 콘텐츠를 재사용하더라도 비공개 메모·수정·업로드 접근 권한은 맵별로 확인한다. 복제는 원본과 대상의 저장 항목을 연결하는 이력이며 상대방에게 원본 개인 맵 접근 권한을 부여하지 않는다.

**첫 베타 완료 조건**

1. 두 사람 모두 기존 개인 맵이 있는 상태에서 코드로 연결해 공유 맵을 만들 수 있다.
2. 각자가 초기 복제를 안 함·선택·전체 중에서 고르고 개인 맵을 계속 쓸 수 있다.
3. 연결한 뒤에도 양방향으로 장소를 복제할 수 있다.
4. 새 장소를 개인·공유·둘 다에 저장하고 실제 등록 위치를 확인할 수 있다.
5. 복제 후 한 맵의 수정·삭제가 다른 맵의 사용자 기록을 바꾸지 않는다.
6. 반복 복제로 같은 지점의 핀이 늘지 않고 출처·메모가 보존된다.
7. 개인 메모·사진은 선택해 공유하며 상대의 개인 맵을 조회할 수 없다.
8. 연결 해제 후 개인 기록은 유지되고 종료된 공유 맵에 저장·복제할 수 없다.
9. 처리 중 연결 해제와 둘 다 저장의 부분 실패를 맵별로 확인·보완할 수 있다.

개인 맵·코드 연결·초기 및 이후 복제·저장 위치 선택은 V0.1부터 첫 베타의 P0 범위로 둔다. 공유 맵의 관심·수동 후보·최종 선택은 통합 기획서대로 V0.5에서 검증한다. 여러 개인 맵이나 여러 활성 공유 맵은 이번 요구의 초기 구현 범위와 분리하여 추후 수요로 판단한다.
