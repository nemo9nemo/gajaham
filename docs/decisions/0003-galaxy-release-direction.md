# 0003 갤럭시 우선 2단계 출시와 광고 수익 검토

**2026-11-03 후속:** Android/Play 우선 출시 경로는 웹앱 우선인 [결정 0007](0007-webapp-first-low-cost.md)로 대체한다. 아래는 요구 이력이며 Galaxy 브라우저 우선·광고 수익화 목표 외 세부 플랫폼 계획을 현재 출시 기준으로 사용하지 않는다.

- 날짜: 2026-10-19
- 상태: 10월 19일 요구 이력. 로그인 단계·개인 기록 클라우드 복구 제안은 2026-10-26 [결정 0005](0005-login-and-device-local-records.md)로 대체. 그 밖의 세부 실행안은 제안
- 출처: 사용자 요청 '1차: 로그인 제외 / 2차: 실제 로그인까지', '갤럭시 우선', '광고를 통해 수익 창출', 출시 보완·기획·마케팅 검토

## 확정한 요구

1. 1차는 로그인을 제외하고, 2차에는 실제 로그인을 다룬다.
2. 갤럭시 사용 경험을 우선한다.
3. 광고 수익을 목표로 출시 준비와 마케팅을 함께 검토한다.
4. 기획·구현·검증·리뷰는 기존 결정 0002에 따라 Codex가 맡는다.

## 실행 제안과 미확정 경계

[출시 기획](../release/galaxy-launch-plan-2026-10-19.md)에 로그인 없는 로컬 개인 앱 → 실제 로그인·복구·2인 공유 → 검증된 DM 수신의 순서를 제안했다. 1차 공개 여부와 월 예산이 아직 확인되지 않아 공개 가능한 1차·1인 소액 운영을 가정했다. 기능별 단계 배치와 비용·성과 목표를 사용자의 별도 확정이나 구현 완료로 표시하지 않는다.

Kotlin·Compose·Room·WorkManager, Google Play 우선 배포, 제한적인 AdMob 네이티브 광고를 기술·운영 제안으로 기록한다. 실제 Android 도입과 버전·명령은 후속 구현 브리프에서 정한다. 정적 `web/`의 의존성 없는 스택 결정은 계속 적용된다.

기존 10월 10~12일 기획의 DM·모바일 웹 우선과 첫 베타 로그인 전제는 최신 요구에 맞춰 재조정한다. DM은 폐기하지 않고 공식 수신·자료 확보·심사 조건의 실증을 먼저 요구한다. 개인 맵 비공개·선택적 복제·맵별 독립 편집·저장 직전 권한 검사는 유지한다.

## 구현과 검증 상태

현재는 정적 목업 58개 화면이다. Android 설치 파일·실제 로그인·DM·DB·광고 연동·스토어 제출·마케팅 집행은 이번 검토로 수행하거나 완료되지 않았다. 출시 검사의 증거를 확보할 때까지 서비스 출시 준비 완료로 표시하지 않는다.

2026-10-20 후속: [결정 0004](0004-android-local-core.md)에 따라 [APP-01](../plans/APP-01-android-local-core.md) Android 개인 저장 기반을 구현한다. 위 상태는 10월 19일 기획 검토 시점의 기록이며, 이후 구현·검사는 APP-01 증거를 따른다.
