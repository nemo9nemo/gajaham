# 0002 Codex 단독 작업과 독립 리뷰

- 날짜: 2026-10-19
- 상태: 확정
- 출처: 사용자 요청 “응. 앞으로 클로드 사용하지 않을거야. 스스로 전부 마무리 해.”

## 배경

UI-02의 비공개 맵 ID 노출 문제는 수정·90개 테스트·독립 Codex 리뷰를 통과했지만, 이전 Claude 구현 승인 조건 때문에 커밋이 보류됐다. 사용자는 해당 리뷰를 Codex로 대체 승인하고 앞으로 Claude 없이 작업을 마무리하도록 지시했다.

## 결정

1. 기획·설계·구현·검증·리뷰·로컬 커밋은 Codex가 맡는다. Claude 호출·승인·인증 복구를 요구하지 않는다.
2. 구현 리뷰는 별도 읽기 전용 Codex 세션에서 수행하고 근거·실행한 검사·지적을 남긴다. 지적을 확인·수정한 뒤 구현 리뷰 APPROVED를 기록하고 로컬 커밋한다.
3. 커밋된 정확한 SHA는 별도 worktree에서 `main` 대비 재리뷰한다. 통과한 SHA만 Git 제외 경로 `tmp/codex/reviewed.txt`에 기록하며, 새 커밋이 생기면 다시 리뷰한다.
4. 명시적인 작업 요청에 포함된 통상적인 구현·검증·로컬 커밋은 추가 확인 없이 진행한다. 새 제품 범위가 불명확하거나 사용자의 결정이 필요한 경우에만 묻는다. push·PR은 별도 사용자 요청 시 진행하고 병합은 사용자가 확인한다.
5. 과거 Claude 작성 문서·리뷰 기록은 사실 그대로 보존한다. 기존 분업 문서는 새 절차로 연결하고, `.claude/skills/`는 과거 도구 설정으로 취급한다. 이를 현재 Claude 호출 지시로 사용하지 않는다.

실행 절차는 [Codex 작업·리뷰](../development/codex-workflow.md), 브랜치·전달 규칙은 [Git 절차](../development/git-workflow.md)를 따른다. 제품 범위와 정적 목업 스택은 바꾸지 않는다.
