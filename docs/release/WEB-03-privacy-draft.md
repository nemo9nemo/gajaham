# 공개 개인정보 안내 초안과 확정 항목

2026-11-10. 서비스 구현 사실을 바탕으로 app-web/privacy/index.html과 공통 privacy-content.mjs를 작성했다. /privacy/는 로그인 없이 읽을 수 있고 인증 SDK·DB·App Check를 초기화하지 않는다. 앱 내 안내와 같은 내용을 사용한다. 이 초안 작성은 실제 운영자/제공자 계약·국외 처리 확정이나 법률 검토 완료를 의미하지 않는다.

| 항목 | 현재 확인한 구현 | 공개 전 확정할 부분 |
|---|---|---|
| 계정 | 이메일·UID·확인 여부·인증 상태를 Firebase Auth로 처리. 가자함 DB에 비밀번호 저장 안 함 | 실제 운영 주체·문의 담당·본인 확인/권리 행사 절차 |
| 개인 기록 | 장소·주소·출처·메모/메뉴·분류·방문·생성/수정/휴지통 상태를 UID별 D1 저장 | 실제 제공 목적과 처리 근거·국외 처리 고지 |
| 게스트 | 브라우저 IndexedDB만, 사용자 명시 선택 후 계정 이동 | 사이트 주소 변경 시 원본 자동 이동 없음 안내 유지 |
| 보호/접속 | Hosting/Auth/App Check·reCAPTCHA·Workers/D1 이용. 앱은 원문/토큰을 로그에 쓰지 않음 | 각 제공자의 접속/보안 정보·계약·처리 국가/보존 조건·수탁자 연락 경로 |
| 삭제 | 휴지통30일·접속 시 순차 정리, 원문 없는 요청 ID는 탈퇴까지, 탈퇴 pending/완료 확인 | 지연 문의·확인 수단, 실제 운영 삭제/메일 검사 |
| 최소 상태/이력 | 완료 상태7일·호출 제한2일 뒤 정리 대상. D1 Free 자동 복구 이력7일 | 실제 설정 및 공급자 보존·삭제 조건과 일치 여부 |
| 후속 기능 | 광고·분석·DM·공유 없음 | 기능 추가 전에 처리방침/고지·필요한 동의 검토 |

운영자/문의처/시행일/실제 처리 조건이 비어 있으면 페이지에 초안을 표시한다. prepare-release는 이 값과 privacyReviewed=true가 없으면 공개 번들을 생성하지 않는다. 입력의 형식/길이 검사는 내용의 사실성이나 법적 적정성을 자동 인증하지 않는다. 실제 타인의 이메일·임의 국가/법적 근거를 채우지 않았다.

참고한 공식 자료: [개인정보 포털의 2026 작성지침/표준안 목록](https://www.privacy.go.kr/front/bbs/bbsList.do?bbsNo=BBSMSTR_000000000049), [Firebase 개인정보/보안 및 계약 안내](https://firebase.google.com/support/privacy), [Cloudflare D1 보존/제한](https://developers.cloudflare.com/d1/platform/limits/). 제공자의 자료를 가자함의 실제 처리방침으로 그대로 복제하지 않는다. 지침 목록과 제공자 일반 안내만으로 가자함의 적용 법률/국외 이전 근거가 확정됐다고 주장하지 않는다.
