# 가자함 · 현재 출시 준비 상태

2026-11-10 · [WEB-03 브리프](../plans/WEB-03-release-preparation.md) · [검사 증거](../validation/WEB-03-release-preparation.md)

현재는 장소 링크·메모를 보관하는 개인 웹앱이다. 로그인하면 지원 기기/브라우저에서 계정 원본을 재조회한다. 실제 지도·상대 연결·공유·DM·자동 분석·광고는 아직 없으며 출시했다고 소개하지 않는다. 설치/도메인 구매·Blaze/결제 연결은 이용·개발 선행 조건이 아니다.

## 계정 없이 마친 작업

| 항목 | 상태 | 근거 |
|---|---|---|
| 계정/게스트 기록·동시 편집·명시적 이동·삭제/탈퇴 보안 | 로컬 완료 | 기존 흐름+WEB-03 공식 Emulator/workerd/D1·Chromium 검사 |
| 공개 개인정보/탈퇴 안내 URL과 인앱 안내 통일 | 로컬 완료 | /privacy/는 무로그인·인증/DB 초기화 없음. 초안/미확정 정보 표시 |
| 공개 프로젝트·기본 URL·App ID·D1 설정 교차 검증 | 완료 | 미설정·소유자 변조형 URL·다른 프로젝트·비밀/토큰 입력 거절 |
| 배포 파일 생성·정확한 CSP·무결성 목록 | 도구 완료 | 새 tmp/release 폴더에 Hosting/Worker/D1만 생성. 원격 배포 없음 |
| Cron 실패/다른 삭제 계속·고정 오류/집계 점검 | 로컬 완료 | pending 유지/재개·개인정보 없는 health.sql 검사 |
| 운영·키 회수·사용량·사고/삭제 대응 절차 | 초안 완료 | [운영 절차](WEB-03-operator-runbook.md). 원격 실증은 아직 없음 |
| 보안 검사·독립 리뷰·로컬 커밋 | 검사/리뷰 기록 참조 | 웹/Worker audit0. CLI moderate14는 별도 잔여/노출 제한 |

## 사용자 확인이 필요한 항목

지금 바로 필요한 확인과 서버 연결 뒤 확인을 나눈 [사용자 다음 단계](USER-NEXT-STEPS.md)를 우선합니다. 공개 처리 안내는 Codex가 실제 설정에 맞게 작성하고 사용자에게 사실/공개 여부를 확인받습니다. 프로젝트/DB/키/JSON을 사용자가 직접 구현할 필요는 없습니다.

| 사용자 확인 | 필요한 이유 | 그 뒤 Codex가 맡을 작업 |
|---|---|---|
| Google/Cloudflare 소유 계정 로그인·본인/약관 확인 | 계정 권한/소유 확인을 대신할 수 없음 | 실제 무료 프로젝트/DB/Auth/App Check/secret 연결 |
| Spark·Workers Free·결제수단/유료 구독/Cloud Billing 미연결 확인 | 원격 계정의 청구 상태는 코드 형식 검사로 알 수 없음 | 무료 설정 유지·사용량/운영 오류 검사 |
| 공개 운영자·실제 문의 이메일/URL·시행일·실제 개인정보 처리 안내 확정 | 임의의 개인정보/국가/법적 근거를 공개하지 않음 | 개인정보 문안 반영·진짜 설정으로 번들 재생성 |
| 실제 메일함의 확인/재설정 링크 확인 | 메일함·본인 링크에 접근할 수 없음 | 메일/API/회수·삭제 결과 검사 기록 |
| Galaxy Samsung Internet/Chrome 조작/확인 | 실기기 상태에 접근할 수 없음 | 두 기기 기록/편집 충돌/탈퇴·화면 검사 지원 |

카드·유료 요금제·별도 도메인·서버 구매는 사용자 할 일에 포함하지 않는다. 비밀번호/인증 키를 채팅이나 공개 문서에 보내지 않는다.

## 계정 연결 후 Codex가 이어서 할 작업

무료 D1/Worker/Auth·App Check와 기본 주소 설정, secret 최소권한 연결, 실제 Free CPU10ms·DB 호출/저장 한도·메일·보안 헤더·Cron/삭제 재시도 검증, 실제 배포와 운영 URL의 두 브라우저 검사는 **연결 정보 부재로 미실행**이다. 이 작업을 사용자에게 수동 구현/명령 실행으로 넘기지 않았다. 실제 운영 정보가 준비되면 같은 무료 정책 안에서 이어서 진행한다.

가상 설정으로 생성한 fixture 번들은 배포용이 아니다. 운영 계정·실제 문의처·개인정보 확정이 없는 상태에서 공개 출시 완료로 표시하지 않는다. [실제 사용/비용 조사](../research/no-billing-stack-2026-11-09.md)와 [개인정보 확정 항목](WEB-03-privacy-draft.md)을 함께 따른다.
