# 최종 런칭 체크리스트

2026-11-10 · 사용자 요청 “전부 push하고 최종 런칭을 위해 정리”. [현재 상태](WEB-03-readiness.md)와 [운영 절차](WEB-03-operator-runbook.md)를 한 순서로 모았다. 이 체크리스트 작성/소스 push는 공개 서비스 배포 완료가 아니다.

## 최종 검토 대상과 이전 작업

최신 통합 대상은 `codex/WEB-03-release-preparation`이다. 코드·개인정보 초안·출시 도구·운영 절차와 이전 구현 이력을 포함한다. 이전 브랜치도 버전 이력 보관용으로 전송하되, 이전 단계 정책/코드를 따로 병합해 최신 웹 정책을 되돌리지 않는다. 이력용 PR은 draft로 구분하고 최신 통합 PR을 우선 검토한다. UI-02의 별도 커밋 이력도 보존한다.

원격 main은 기존 기준점이며, 사용자가 PR을 검토해 병합하기 전에는 직접 갱신하지 않는다. 로컬 리뷰 기록과 push한 정확한 SHA가 일치하는지 확인하고 PR별 독립 리뷰 결과를 남긴다. 최종 PR 주소·push/리뷰 완료 여부는 실제 원격 결과로 보고하며 미실행을 완료로 표시하지 않는다.

## 이미 확인한 것과 공개 판정

WEB-03의 고유 로컬 검사27개, production 번들/보안 헤더 설정·Worker dry-run·독립 코드 리뷰가 완료됐다. 웹앱/Worker audit0과 기존 개발 Emulator CLI의 moderate14 잔여/격리를 구분한다. [검사 기록](../validation/WEB-03-release-preparation.md)을 따른다.

운영자 정보가 비어 있는 안내 초안·fixture 번들·localhost 주소는 공개 출시 자료가 아니다. 예산 알림으로 과금 한도를 대신하지 않으며 무료 한도 초과 시 기능이 제한될 수 있다. CPU/인증/삭제가 무료 환경에서 통과하지 않으면 공개 전에 구현/설정을 조정한다. 계정 인가·App Check·삭제 차단을 끄거나 유료 전환으로 해결하지 않는다.

사고 시에는 [운영 절차](WEB-03-operator-runbook.md)의 사용량/삭제·키 회수·롤백을 따른다. D1 자동 복구 이력의 존재와 서비스의 복구 기능은 별개이며, 현재 DB를 과거로 돌리는 복구는 별도 검증 전 공개 중 실행하지 않는다.
