# 지금 필요한 확인과 나중의 확인

2026-11-10. 계정/프로젝트·실제 운영 정보는 아직 연결되지 않았다. 사용자가 설정 파일이나 서버 코드를 작성할 필요는 없다. 개발·DB/인증·무료 구성·배포와 자동 검사는 Codex가 맡는다.

## 지금 사용자에게 필요한 세 가지

| 순서 | 직접 할 일 | 완료 기준 | Codex가 이어서 할 일 |
|---|---|---|---|
| 1 | [통합 PR #3](https://github.com/nemo9nemo/gajaham/pull/3)을 확인하고 main에 병합 | 최종 코드/검사·미실행 한계를 확인한 뒤 병합 | 이후 실제 운영 준비를 이 코드 기준으로 이어감 |
| 2 | [Firebase](https://console.firebase.google.com/)에 사용할 Google 계정과 [Cloudflare](https://dash.cloudflare.com/) 계정 준비·로그인/본인/약관 확인 | 본인이 소유·관리하는 계정에 접근 가능. 결제수단·유료 플랜을 연결하지 않음 | 필요한 CLI 인증 흐름 지원, 무료 프로젝트·DB·Auth/App Check·secret·기본 URL 연결과 무료 상태 점검 |
| 3 | 공개 운영자/문의 담당 표시명과 실제 문의 이메일/URL 선택 | 표시할 이름과 실제 연락 가능한 문의처 확정. 미정이면 공개 배포 전까지 준비 필요 | 개인정보/국외 처리 안내 초안 작성·확정 요청, 시행일 제안·반영, 공개 설정/번들 생성 |

콘솔에 로그인한 것과 이 컴퓨터의 배포 CLI가 인증된 것은 별개일 수 있다. 계정 준비 뒤 Codex가 인증 흐름을 안내하고, 본인 로그인·동의 화면만 사용자가 처리한다. 비밀번호·일회용 코드·토큰·서비스 계정 키를 채팅에 보내지 않는다. 계정이 여러 개라면 어느 계정을 가자함 운영에 쓸지 선택한다.

프로젝트 생성·DB 설정·App Check·관리 키 처리·JSON 입력·국외 처리 문안 작성을 사용자에게 숙제로 넘기지 않는다. 실제 무료 플랜/청구 상태는 접근 가능한 콘솔/공식 API로 Codex가 점검하고, 결제/약관과 소유 계정에 대한 최종 사실 확인은 운영자가 함께 한다. 카드·Blaze·Cloud Billing·Workers Paid·도메인/서버 구매는 필요 항목이 아니다.

## 서버 연결 뒤 사용자 협조가 필요한 확인

| 확인 | 시점 | 사용자 협조 |
|---|---|---|
| 실제 메일 | 인증 제공자/기본 주소 설정 뒤 | 가입 확인·비밀번호 재설정 메일을 받아 링크를 열기 |
| Galaxy Samsung Internet/Chrome | 테스트할 운영 URL이 준비된 뒤 | 같은 계정의 기록·수정·삭제·탈퇴를 휴대전화에서 확인하기 |
| 최종 개인정보/공개 내용 | 실제 제공자·지역·보존 설정이 확인된 뒤 | Codex가 작성한 실제 처리 안내와 공개 정보를 확인하기 |

지금 메일 테스트나 Galaxy 화면을 확인할 수 있는 실사용 URL은 아직 없다. localhost/가상 fixture로 이 항목을 완료 처리하지 않는다.

## 남은 작업의 담당과 순서

1. Codex: 무료 프로젝트/D1·이메일 인증/App Check·최소권한 secret·기본 주소 연결.
2. Codex: 실제 설정 교차 검사, 새 출시 번들 생성 및 무결성 대조.
3. Codex + 사용자 메일/기기 협조: Free CPU/DB 한도·토큰/권한·보안 헤더·두 기기 기록·충돌·탈퇴/Cron 검사.
4. Codex: 검사 결과와 개인정보/운영 정보 확정 후 공개 배포·운영 URL 재확인.
5. 운영자 + Codex: 사용량·오류·삭제 지연 집계와 문의 대응.

원격 소스 자동검사는 실제 배포/무료 운영 검사와 다르다. 현재 구조는 개인 보관함이며 실제 지도·상대 연결·공유·DM·자동 분석·광고는 후속 기능이다. [전체 체크리스트](FINAL-LAUNCH-CHECKLIST.md), [운영 절차](WEB-03-operator-runbook.md)를 함께 따른다.
