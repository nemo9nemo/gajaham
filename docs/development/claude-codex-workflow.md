# 이전 Claude·Codex 분업 절차

2026-10-19 사용자 요청으로 이 절차는 [Codex 작업·리뷰 절차](codex-workflow.md)로 대체됐다. Codex가 기획·설계·구현·검증·독립 리뷰·로컬 커밋을 맡으며 Claude 호출·승인·계정 복구를 기다리지 않는다.

이 경로는 기존 브리프와 커밋의 링크를 유지하기 위해 남긴다. 과거 분업·작성자·리뷰 결과는 Git 이력과 당시 브리프에 보존되어 있다. 현재 작업에는 [AGENTS.md](../../AGENTS.md), [결정 0002](../decisions/0002-codex-only-workflow.md), [Git 절차](git-workflow.md)를 적용한다.
