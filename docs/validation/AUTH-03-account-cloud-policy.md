# AUTH-03 서버 개인 기록·여러 기기 조회 검증

기준: 2026-11-03 / [결정 0008](../decisions/0008-account-cloud-records.md), [계정 계약](../contracts/web-account-data.md), [브리프](../plans/AUTH-03-account-cloud-policy.md)

이번 정책 작업은 문서 정합·상대 링크·`git diff --check`·독립 문서 리뷰만 수행하고 브리프에 기록한다. 아래 기능은 모두 **계획·미실행**이다. 실제 웹/Firestore가 없는 상태에서 동작 통과·운영 설정 완료로 표시하지 않는다.

| ID | 시나리오 | 기대 결과/필요 증거 |
|---|---|---|
| AC01 | 독립 브라우저A에서 계정A 저장, B에서 같은 계정 로그인 | 서버에 저장 완료된 장소·메모·방문·처리함/휴지통 조회. 설치 불필요. 실제 서버/Emulator 연동 증거 |
| AC02 | 사이트 데이터 삭제 후 재로그인·지원 모바일/PC 접속 | 서버 원본 유지/재조회. 게스트는 이 보장에 포함하지 않는 안내 |
| AC03 | A/B 계정 전환·게스트 복귀·다중 탭·늦은 응답 | UID/세대별 구독·캐시 격리, 다른 사용자 노출·잘못된 저장 없음 |
| AC04 | 게스트/다른 UID/만료 인증/소유자 변조 직접 API | 개인 목록·읽기·추가·수정·삭제/복원 모두 서버 인가. 관리자 키 클라이언트 미포함 |
| AC05 | 통신 중단·서버 거절·응답 불명확·연속 저장/재시도 | 서버 확인 전 완료 표시 없음, 입력/미완료 안내, 동일 요청 중복 생성 없음 |
| AC06 | 두 기기의 같은 기록 동시 수정·삭제/복원 경합 | 버전/트랜잭션 검사, 오래된 폼의 무음 덮어쓰기 방지·충돌 안내 |
| AC07 | A 수정/휴지통/복원/영구 삭제 후 B 재연결 | 같은 계정 서버 최신 결과 반영. 미전송 입력의 자동 반영 약속 없음 |
| AC08 | 게스트 계정 저장 취소/허용·중복·부분 실패·전환 중 재시도 | 자동 업로드 없음. 선택 UID 고정·서버 성공 항목만 이동 정리·중복 보존·중복 생성 방지 |
| AC09 | 탈퇴 재인증 실패·정리 중 종료/통신 실패·인증 삭제만 성공 | 실패 전 원본 유지/명시 상태, 지속되는 서버 pending·쓰기 차단/재시도. 전체 삭제 미확인 시 완료 단정 금지 |
| AC10 | 탈퇴/정지 후 다른 기기의 기존 토큰/구독·같은 이메일 재가입 | 새 서버 접근 차단·새 UID에 과거 기록 연결 없음. 오프라인 캐시 원격 즉시 삭제 보장 금지 |
| AC11 | 개인↔공유 선택 복제 후 수정/삭제 | 같은 계정 기기 간 반영과 다른 맵 사본 독립 동시 충족. 타인 개인 맵 비공개 |
| AC12 | 정식 주소 변경·비정식/preview·게스트 origin 분리 | 같은 운영 프로젝트/UID의 계정 재조회, 게스트 자동 이전 약속 없음. 인증 허용 주소/키 제한 확인 |
| AC13 | 운영 리전/고지·네트워크·로그·한도/백업·삭제 | 서버 보관 고지·민감 기록 로그 없음·개인+공유 합산 비용/중단 대응. 실제 메일/배포는 별도 |

후속 WEB-01에서 정확한 앱/SDK·Rules/API·Emulator·검사 명령을 고정한다. 공식 Emulator 통합과 실제 두 브라우저 조회/갱신, 운영 프로젝트·지원 기기 증거를 구분한다.
