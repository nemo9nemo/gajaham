# WEB-00 웹 전환 점검과 후속 검증

**2026-11-03 후속:** 아래 WEB-00 실행 증거/초기 시나리오는 당시 이력이다. 로그인 원본 로컬 전용·다른 기기 복구 불가 시나리오는 [결정 0008](../decisions/0008-account-cloud-records.md)과 [AUTH-03 AC01~AC13](AUTH-03-account-cloud-policy.md)으로 대체한다. 현재 서버 개인 기록·두 기기 조회는 미구현/미검사다.

기준: 2026-11-03 / [브리프](../plans/WEB-00-webapp-transition.md), [결정 0007](../decisions/0007-webapp-first-low-cost.md), [웹 로컬 계약](../contracts/web-local-data.md).

## 웹 기능 구현 때 필요한 시나리오

전부 **계획·미실행**이다. Android/Emulator의 통과 기록으로 대신하지 않는다. 후속 브리프가 정확한 스택·명령·증거 경로를 정한다.

| ID | 시나리오 | 기대 결과 |
|---|---|---|
| WV01 | 게스트 링크 입력·중복·수동 확정·재실행/강제 종료 | 서버 계정 없이 IndexedDB 커밋 후 저장 성공, 재실행 보존 |
| WV02 | 스키마/웹앱/서비스 워커 업데이트와 롤백 | 기존 원본·소유 영역 보존, 호환 실패 시 무단 초기화/성공 표시 없음 |
| WV03 | 게스트→계정A 선택 이동→B→로그아웃·다중 탭 지연 쓰기 | UID/세대별 격리, 중복 보존, 옛 작업의 새 영역 쓰기 차단 |
| WV04 | 공식 웹 SDK+Auth Emulator 가입/확인/재설정/재인증/탈퇴 | 가짜 로그인 없이 상태 전이, 암호/토큰 로그 없음. 실제 운영 메일 도착은 별도 검사 |
| WV05 | 탈퇴 중 종료·재시도·원격 성공/로컬 실패·세션 무효 | pending 보존/쓰기 차단·불명확 결과 안내, 다른 계정 원본 보호 |
| WV06 | 오프라인·용량 초과·저장 권한 거부·저장소 회수 | 저장 실패를 성공으로 안내하지 않음, 개인 원본 서버 백업으로 우회하지 않음 |
| WV07 | 사이트 데이터 삭제·PWA 제거·재설치·다른 브라우저/기기 | 로그인 복구 없음. 아이콘 제거만으로 데이터 삭제를 보장하지 않는 안내와 실측 |
| WV08 | web.app/firebaseapp.com/preview/새 도메인으로 접근 | 하나의 정식 origin에서만 개인 저장 시작, 주소가 달라져 자동 복구된다고 안내하지 않음 |
| WV09 | Galaxy Chrome·Samsung Internet·Instagram 인앱의 붙여넣기/설치/공유 수신 | 브라우저별 지원표·실기기 증거, 미지원 시 붙여넣기 경로. 원본 링크의 서버 전송/로그 여부 확인 |
| WV10 | 지도·검색·동명 지점·핀 수정·429/오프라인 | 사용자 확정 보존·미확정 저장 차단·실패 시 로컬 목록 열람. 키 제한/무료 자격/저장 조건 확인 |
| WV11 | 공유 코드 재발급/만료/동시 수락·직접 API·권한 종료 중 복제 | 로그인/이메일 확인·2인 제한·원자적 인가. 다른 사용자의 개인 맵은 서버/목록에 없음 |
| WV12 | 선택 공유·사본 편집·공유 종료·탈퇴/마지막 참여자 | 선택 필드만 전송·맵별 독립, 보존/정리 계약과 일치. 개인 원본 동기화 없음 |
| WV13 | 악성 URL/메모·CSP·서비스 워커 캐시·네트워크 캡처 | 입력 안전 렌더, 인증/개인 원본 누출·공유 응답의 앱 셸 캐시 없음 |
| WV14 | 무료 한도 소진·배포 실패·롤백·광고 거부/실패 | 서비스별 중단/대체 안내·사용량 확인, 광고가 저장을 막지 않음, 유료 자동 활성화 없음 |

공개 완료는 운영 프로젝트·메일·HTTPS·정책/문의·브라우저 증거와 실제 제공 기능의 시나리오를 확인한 뒤 판단한다. 공유 서비스·DM·광고 승인은 각 단계의 별도 완료 조건이다.
