# AUTH-01 기능·보안·데이터 생명주기 검증 시나리오

기준: 2026-10-26 [정책 계약](../contracts/auth-and-guest.md). **전체 항목은 설계한 시나리오이며 미실행**이다. 기존 저장 앱의 39개 검사·정적 목업 164개 검사를 실제 로그인/삭제 정책 검사로 재사용하지 않는다.

| ID | 검사 | 예상 결과·필요 증거 |
|---|---|---|
| AU01 | 첫 실행에서 비로그인 선택, 오프라인 개인 저장·재시작 | 서비스 계정 생성 없이 정상 저장/유지. 새 설치에서 손실 안내 확인 |
| AU02 | 로그인 여부 양쪽에서 업데이트·재실행 | 기존 개인 기록 보존, 새 영역/스키마 마이그레이션이 일괄 초기화하지 않음 |
| AU03 | 이메일 가입·확인 메일·확인 취소/만료·재전송 | 실제 인증 제공자/메일 증거, 미확인 계정은 연결 차단·개인 이용 가능 |
| AU04 | 잘못된 비밀번호·가입 여부별 로그인/재설정·반복 요청 | 공통 안내·호출 제한, 민감 정보 로그 없음, 기존 데이터/모드 보존 |
| AU05 | 게스트가 초대 발급/코드 확인/연결/공유 API 직접 호출 | 서버가 미인증 거절, 상대 정보·코드 내용·개인 기록 노출 없음 |
| AU06 | 이메일 미확인·만료/회수 토큰·삭제/정지 계정으로 연결 | 서버 거절, 로컬 상태값 조작으로 우회 불가, 재인증 안내 |
| AU07 | 로그인 후 보류한 코드 재개·만료·재발급·동시 수락 | 재검증·명시적 확인, 이전 코드 무효·단일 사용·정원/활성 연결 제한 보장 |
| AU08 | 게스트 기록의 계정 내 로컬 이동/취소/오류/중복 | 사용자 선택 전 업로드 없음, 실패 시 원본 보존, 덮어쓰기·타 계정 열람 없음 |
| AU09 | A 로그아웃→게스트→B 로그인→A 재로그인 | 로컬 영역/출처 UNIQUE 분리, A 기록·공유 캐시가 게스트/B에게 노출되지 않음 |
| AU10 | 연결 성공/복제/권한 종료가 개인 맵에 미치는 영향 | 선택한 장소만 공유, 상대 개인 목록 비공개, 저장 직전 인가·맵별 독립 편집 |
| AU11 | 로그인/비로그인 각각 앱 삭제→재설치 | **개인 맵·처리함·휴지통 0건**. 같은 계정 로그인도 개인 원본을 복구하지 않음. 계정/공유 재조회는 별도 표시 |
| AU12 | Android OS 백업 복원·Galaxy Smart Switch/기기 이전 | 개인 원본 복원 차단 실기기 증거. `allowBackup=false`/XML만으로 통과 표시 금지 |
| AU13 | 출시 APK의 JSON 백업/가져오기와 우회 진입 | UI/라우트/파일 callback·복구 경로 미제공, 과거 외부 파일 회수/삭제를 했다고 주장하지 않음 |
| AU14 | 앱/서버/인증·SDK 요청·오류 수집의 실제 데이터 흐름 | 개인 원본을 백업/동기화하는 서버 컬렉션/API·숨은 업로드 없음. 인증/지도/광고 통신은 실제 범위에 맞게 고지 |
| AU15 | 비밀번호 재설정 후 동일 설치/재설치 비교 | 동일 UID의 남은 로컬 영역만 열람, 재설치의 삭제된 개인 원본 복구 없음 |
| AU16 | 계정 탈퇴·재인증 실패·오프라인/재시도·재가입 | 앱/외부 웹 요청 경로, 명확한 처리 상태·권한 회수·현재 계정 로컬 정리. 새 UID가 이전 영역을 열지 않음 |
| AU17 | 2차 Google/Kakao 성공·취소·실패·같은 이메일/다른 계정 충돌 | 제공자 검증·명시적 연결·안정적 UID. 이메일만으로 병합/타 계정 열람 없음 |
| AU18 | 로그아웃·탈퇴·네트워크 오류와 공유 접수/편집이 동시 발생 | 개인 저장 보존, 계정 소유 영역 혼입·권한 종료 후 서버 쓰기 없음 |

실행할 계층: 로컬 도메인/Room 마이그레이션·화면 검사, 인증/서버 에뮬레이터와 직접 요청 인가 검사, 실제 운영과 분리한 인증 프로젝트의 메일·세션/탈퇴 통합 검사, Galaxy 설치·삭제·백업/이전·외부 앱 검사. 명령·SDK 버전·대상 기기는 후속 구현 브리프에서 고정하고 실행한 항목만 증거를 남긴다.
