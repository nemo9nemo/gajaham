# 앱 외부 계정 삭제 페이지

공식 Firebase 이메일/비밀번호로 최근 인증 후 인증 계정을 직접 삭제한다. 개인 기록은 서버에 없으며 웹은 설치된 앱의 로컬 DB에 접근하지 않는다. 앱 탈퇴와 데이터 초기화/앱 삭제의 차이를 본문에 안내한다. 상대 연결·공유 서버는 현재 제공하지 않는다.

`config.mjs`에 **공개 web API key**를 설정한 뒤 이 디렉터리의 index/style/config/delete-account 파일만 HTTPS로 배포한다. 서비스 계정 키·관리자 토큰은 넣지 않는다. 실제 프로젝트·공개 도메인·키 제한·메일 설정·Play 계정 삭제 URL 등록은 아직 없다. 기본은 미설정 안내와 비활성 버튼이다. 운영 배포에서 CSP의 로컬 에뮬레이터 `http://127.0.0.1:9099` connect-src 항목을 제거하고 프레임 삽입 금지 헤더(frame-ancestors 'none' 또는 X-Frame-Options DENY)를 서버에서 제공한다. meta CSP로 frame-ancestors를 적용했다고 주장하지 않는다.

로컬은 Node24 `node account/serve.mjs` → http://127.0.0.1:5180 . `?emulator=1`은 localhost/127.0.0.1에서만 허용하며 공식 demo Auth Emulator의 9099로 연결한다. 실제 호스트의 쿼리로 운영 인증 목적지를 바꿀 수 없다. 5180 서버는 허용한 네 파일만 읽고 외부 네트워크에 바인딩하지 않는다. 검사 후 서버를 종료한다.

`node --test account/delete-account.integration.mjs`는 실제 공식 로컬 Emulator와 페이지의 실제 스크립트를 최소 DOM 테스트 환경에서 실행한다. 가상 계정을 생성하고 잘못된 암호/중복 제출/정상 삭제/암호 초기화를 검사한다. 브라우저 렌더링·CSP 검사는 별도로 수행한다. 비밀번호·토큰·이메일을 테스트 출력에 넣지 않는다.

배포 이후에는 실제 HTTPS에서 정상 삭제·에러·속도 제한·접근성·모바일 레이아웃을 다시 확인한다. 이 산출물을 실제 공개 사이트 또는 심사 완료로 취급하지 않는다.
